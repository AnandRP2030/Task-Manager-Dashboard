# Learning & Teaching Guidelines

## Conceptual Deep-Dives & Interview Notes
- Whenever introducing a new foundational or advanced database / backend concept (e.g. Transactions, Indexes, Normalization, Query Optimization, Locks, Connection Pooling, Isolation Levels, etc.):
  1. Provide a concise, structured study note formatted for easy copy-pasting.
  2. Include a **"💡 Real-World Problem"** section explaining why the concept exists.
  3. Include a **"🛡️ The Solution / Code Example"** section directly mapped to the project codebase.
  4. Always add an **"🧠 Interview Bonus"** section highlighting key terms, common trap questions, and talking points expected in technical interviews.
